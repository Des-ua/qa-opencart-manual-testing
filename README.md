# Manual QA Testing — OpenCart Demo

## Project Overview

This repository contains a manual QA testing project for an e-commerce web application based on the **OpenCart Demo** platform.

The goal of the project is to demonstrate **junior-level manual QA skills**, structured testing approach, and the ability to create clear and professional test documentation.

---

## Application Under Test

* Name: OpenCart Demo
* Type: E-commerce web application
* URL: [https://demo.opencart.com/](https://demo.opencart.com/)
* Platform: Web (Desktop browser)

---

## Testing Scope

### In Scope:

* Smoke testing
* User Registration
* User Login
* Product Page functionality
* Shopping Cart functionality
* UI and form validation

### Out of Scope:

* Payment systems
* Backend and database testing
* Security testing
* Admin panel

---

## Testing Types

* Smoke Testing
* Functional Testing
* UI Testing
* Manual Testing

---

## Test Artifacts

The following test documentation was created as part of this project:

* Test Plan
* Smoke Checklist
* Registration Checklist
* Login Checklist
* Product Page Checklist
* Cart Checklist
* Test Summary Report

All artifacts are stored in structured folders within this repository.

---

## Testing Approach

1. Smoke testing was performed first to verify application availability and stability.
2. After successful smoke testing, functional testing was executed using checklists.
3. Core user flows for guest and registered users were tested:

   * Product browsing
   * Viewing product details
   * Adding products to cart
   * Cart management
