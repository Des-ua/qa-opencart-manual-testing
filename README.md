# QA Manual Testing Portfolio — OpenCart Demo

## Project Overview
This repository contains a manual QA testing project for **OpenCart Demo**, an e-commerce web application.  
The project demonstrates practical QA skills including test planning, test case design, bug reporting, SQL queries, and API testing.

---

## Application Under Test
- **Name:** OpenCart Demo
- **Type:** E-commerce web application
- **URL:** https://demo.opencart.com/
- **Platform:** Web (Desktop)

---

## Testing Scope
### Included:
- Smoke testing
- User Registration testing
- Login functionality testing
- Product page testing
- Shopping cart testing
- API testing (REST)
- SQL queries testing
- Bug reporting

### Excluded:
- Payment processing
- Admin panel
- Security testing
- Backend/database performance testing

---

## Test Artifacts
### Checklists
- Smoke Checklist
- Registration Checklist
- Login Checklist
- Product Page Checklist
- Cart Checklist

### Bug Reports
- UI/UX bug reports with detailed steps, expected and actual results

### API Testing
- REST API test cases
- Request methods: GET, POST
- Status code validation
- JSON response validation

### SQL
- Basic SQL queries
- SELECT, WHERE, JOIN
- Data validation examples

### Automation
- Playwright + pytest (Python)
- 2 automated test cases: successful login, invalid password
- Framework: pytest with page fixtures

---

## Tools Used
- Manual testing techniques
- Postman (API testing)
- SQL (basic queries)
- Git & GitHub
- Markdown documentation
- Playwright (basic automation)
- pytest

## Conclusion
The project demonstrates a structured QA approach and readiness for junior QA/manual tester positions, showcasing real-world testing scenarios and documentation practices.

This project was created for educational and portfolio purposes to demonstrate practical manual QA skills and understanding of the testing process.
