# Bug Report: Add to Cart success message disappears too quickly

## Bug ID
BR-001

## Title
Success message after adding product to cart disappears too quickly

## Environment
- Application: OpenCart Demo
- URL: https://demo.opencart.com/
- Browser: Microsoft Edge
- Platform: Web (Desktop)

## Preconditions
- Application is accessible
- User is on the main page
- At least one product is available

## Steps to Reproduce
1. Open the main page
2. Click **Add to Cart** button on any product
3. Observe the success message

## Actual Result
Success message disappears too quickly and may not be noticed by the user.

## Expected Result
Success message should remain visible long enough for the user to read it or until the user closes it manually.

## Severity
Minor

## Priority
Low

## Notes
This issue may affect user experience, especially for new users.
